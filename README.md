# sand-simulation
A reworked sand simulation and my first ever C project

Place sand with LMB - Destroy with RMB
The mouse wheel allows you to change the size of your pen
Number keys allow you to change the material(Sand,Water,Stone,Wall,Dirt,Grass...)

Build with this command(Make sure to have SDL3 installed)
`gcc main.c -LC:\msys64\ucrt64\bin -lSDL3 -o main.exe`
